## Compliance procedure

1. Confirm team registration, event and membership limits against current guidance.
2. Work on a single agreed challenge and keep scope tied to its requirements.
3. Document the timing of research and implementation. The project records distinguish pre-event research from application work beginning on 2026-11-14.
4. Cite external code, data, imagery and literature; verify usage terms.
5. Disclose generative-AI assistance and human responsibilities.
6. Prepare public submission materials in English; verify any subtitle requirements.
7. Complete mandatory fields and check every public link before the actual deadline.

Earlier planning interpreted the FAQ as prohibiting work on the solution before the event [S03]. This repository cannot independently certify compliance; the official event rules govern.

## Requirements and evaluation

| Project requirement | Intended response |
|---|---|
| Layered, multi-mission view | Map, source catalog and provenance cards |
| Surface location or route | Jezero, hypothetical base, editable stops and route representation |
| Marswalk planning | Explicit terrain/resource/return assumptions |
| Scientific opportunities | Source-backed geology, minerals and science stops |
| Scientific validity | Original metadata, uncertainty, review and tests |
| Clear communication | Demonstration, documentation, bibliography and AI disclosure |

The earlier dossier used Impact, Creativity, Validity, Relevance and Presentation as evaluation categories, informed by archived guidance [S04–S05]. Do not treat an archived 2025 guide as the final 2026 rubric.

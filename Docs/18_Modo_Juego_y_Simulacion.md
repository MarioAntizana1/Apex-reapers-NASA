# 18. Game and analyst mode concepts

**Status:** optional product concepts, not a validated simulator or complete game. The current 3D demonstration does not implement all the features proposed here.

## Three connected ideas

| Concept | Intended purpose | Boundary |
|---|---|---|
| Mission Mode | Educational decisions about destination, science, resources and return | Serious-game mechanics do not validate real operations |
| Analyst Mode | Compare explicit what-if parameters | Results only hold under the chosen assumptions/data |
| Mission Brief | Portable explanation of route, parameters, sources and uncertainty | Export remains a planned deliverable |

## Potential educational design

A short mission could ask the user to choose a base, select science stops, allocate time and compare return constraints. A score could reward a source-backed objective and staying within the chosen hypothetical limits.

Such scoring would be a **project-defined heuristic**, not a scientific measure of mission value. Simulated events, resource rates and decorative hazards must be labelled; do not suggest a random event occurred in actual Mars observations.

## What may be evidence-backed

Original imagery, properly interpreted elevation, dated observations, cited geology and source-backed mineral detections can inform the experience [S14, S16, S35–S40, S78–S79].

Actual suit physiology, local obstacle safety, radiation response, dust forecasts and guaranteed resource availability are not established by the current inputs. Resampling a DTM or adding a rock model does not create a validated hazard model.

## Analyst workflow proposal

Choose a documented dataset/version, set parameters, compare alternatives, inspect sensitivity and export the exact assumptions. Keep observed values and user-selected coefficients separate. Record uncertainty and unsupported regions.

## Scope decision

Prioritize the map, provenance, traceable route/assumptions and brief. Optional modes should not replace that core or introduce unsupported “digital twin” claims. The current movement meters, jumps and decorative objects are illustrative interactions, not evidence that Mission Mode or a research simulator is complete.
